## 权限与限制

原候选只批准 join.wps.cn、app.mokahr.com。此次只读开发测试使用正常页面已观察到的资源主机：static-ats.mokahr.com、public-cdn.mokahr.com、cstaticdun-v6.126.net、hm.baidu.com；没有写入候选授权。未观察到的 sentry-fe.mokahr.com 请求被阻止，没有放行；它不影响真实主列表读取。生产声明应只保留实际必需资源，不把统计域名顺便加入权限。

原候选仍只有失败关闭的 HTTP 模块，BLOCKED.md 保留。要完成安装，平台 Agent 应沿现有批准路线续接，改写候选为 browserListing 调用；如需新增必要资源域名，提交真实资源链供页面审核。不要重复 HTTP 封装取证，不受旧方法的历史失败次数永久封锁。最终仍须平台独立列表/三个详情验收，不能依据本报告直接启用。

固定 class 可能随官网发布变化；字段缺失将明确失败，不返回 mock 或成功空列表。只验证该列表第一页，不代表全量校招、社招或所有岗位可投递。
