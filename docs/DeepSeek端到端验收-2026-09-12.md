# DeepSeek 端到端实测（2026-09-12）

## 结论与范围

通过 Ego Lite 在平台执行 DeepSeek 的 Agent 适配、独立验收、自动安装绑定及免费扫描。只测试这一家企业；没有投递，没有运行岗位 AI 分析。

适配器由平台启动的 Agent 编写。测试人员没有在平台外编写该适配器，也没有手工修改信任配置绕过安装验收。

## 本次发现并修复的平台问题

官网岗位数据在招聘页引用的静态 JS 资源内。平台原来把“获取 HTML，再获取其明确引用的数据资源”误判为两页列表请求，导致验收失败。

现允许已批准入口实际引用、位于允许域名内的一个静态资源 GET；仍拒绝猜测资源地址、额外分页、重复资源请求与未批准域名。然后在企业页面点击“仅重新验收（零 Token）”，平台独立验收通过并自动启用绑定。

历史失败任务不会被改写成成功；企业当前安装状态才代表重新验收结果。
