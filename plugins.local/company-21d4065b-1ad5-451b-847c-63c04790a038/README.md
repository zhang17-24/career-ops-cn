# 阿里巴巴校招固定 DOM 适配器

使用平台 `ctx.browserJobs(entry)` 和 manifest 固定选择器，读取已批准列表一页。平台匿名浏览器限制精确域名，不点击、不翻页、不调用模型；候选从真实官网 URL 原样提取字符串 ID，拒绝重复编号和结构异常。没有公开通用 ATS 契约证据，因此复用平台通用 reader，仅选择器属于本企业。

仅返回名称、官网链接、地点、公司及编号；不补造发布时间或描述。列表为空或失败会报未确认，不返回示例岗位。测试数据仅存在 test/ 中。日常运行零模型 Token，本次开发使用 Agent Token。

候选保持禁用。由企业托管平台独立验收一页列表和三个真实详情，通过后安装并绑定；本目录不授予启用权限。历史及最新证据见 ACCEPTANCE.md。
